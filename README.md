# Goal Hunter — GG2+ & Both Halves

Mobile-friendly hosted Node/Express app. It keeps the API-Football key server-side and is ready for Render.

## Render
1. Create a GitHub repository and upload this folder.
2. In Render, create a Web Service from the repository.
3. Build: `npm install`
4. Start: `npm start`
5. Add `API_FOOTBALL_KEY` as a secret environment variable.
6. Set `TIMEZONE` to `Africa/Accra`.

The included `render.yaml` can also be used as a Blueprint.
